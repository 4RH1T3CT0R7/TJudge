# Добавление новых игр

Игра состоит из двух частей:

1. Исполнитель — логика игры в tjudge-cli (Rust).
2. Плагин — метаданные игры в Go-сервере.

## Шаг 1. Логика игры в tjudge-cli

В проекте [tjudge-cli](https://github.com/bmstu-itstech/tjudge-cli):

1. Создайте модуль игры в `src/games/your_game.rs`.
2. Реализуйте trait `Game`: протокол взаимодействия (инициализация, итерации, подсчёт очков).
3. Зарегистрируйте тип игры в CLI-аргументах.
4. Пересоберите Docker-образ `tjudge-cli`.

## Шаг 2. Регистрация GamePlugin в Go

Добавьте плагин в `internal/domain/game/builtin.go`:

```go
_ = registry.Register(&GamePlugin{
    Name:              "your_game",       // Должно совпадать с именем в tjudge-cli
    DisplayName:       "Название игры",   // Отображаемое имя (UTF-8)
    DefaultIterations: 100,               // Итераций по умолчанию
    ScoreMultiplier:   1.0,               // Множитель очков для баланса лидерборда
})
```

| Поле | Описание |
|------|----------|
| `Name` | Уникальный идентификатор `[a-z0-9_]+`. Должен совпадать с именем типа игры в tjudge-cli |
| `DisplayName` | Название для отображения в UI |
| `DefaultIterations` | Сколько итераций по умолчанию в одном матче |
| `ScoreMultiplier` | Множитель для балансировки очков между играми. Например `10.0` для Перетягивания каната, где очки за раунд малы (0 или 1) |

## Шаг 3. Создание игры через API

После запуска сервера создайте запись игры:

```bash
curl -X POST http://localhost:8080/api/v1/games \
  -H "Authorization: Bearer <admin_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "your_game",
    "display_name": "Название игры",
    "rules": "# Правила\n\nОписание в формате Markdown..."
  }'
```

Либо добавьте SQL-миграцию по аналогии с `migrations/000015_seed_games.up.sql`.

## Шаг 4. Добавление игры к турниру

```bash
curl -X POST http://localhost:8080/api/v1/tournaments/<tournament_id>/games/<game_id> \
  -H "Authorization: Bearer <admin_token>"
```

После этого участники смогут загружать программы для игры, и она войдёт в раунды турнира.

## Заметки

- `ScoreMultiplier` подбирается так, чтобы вклад игры в общий рейтинг был сопоставим с Дилеммой заключённого.
- Имя игры должно совпадать в tjudge-cli и в Go-плагине — по нему система сопоставляет записи в БД с исполнителем.
- Правила в Markdown показываются участникам на странице игры: включайте протокол взаимодействия, формат ввода/вывода и ограничения.
