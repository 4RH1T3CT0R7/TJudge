# TJudge - Roadmap и принятые решения

Этот документ фиксирует отложенные задачи и сознательные решения «не делать
сейчас», чтобы они не передумывались заново при каждом обсуждении.
Полный разбор идей с обоснованиями: `docs/ideation/2026-06-09-tjudge-improvement-ideation.md`.

## Сознательно отложено / «не делать сейчас»

| Решение | Причина | Когда пересмотреть |
|---|---|---|
| Password-reset | Фича удалена (миграция 000035 изъята); таблица в развёрнутых БД не используется | При запросе пользователей |
| CSRF middleware | Написан, но не активирован: JWT передаётся в header, а не в cookies - CSRF-вектора нет | Если токены переедут в cookies |
| K8s-деплой | Экспериментальный (`deployments/k8s`); основной путь - blue-green на docker-compose | При горизонтальном масштабировании |
| Read replicas, Redis Cluster | Нагрузка не требует | По метрикам насыщения БД |
| Swiss-/sampling-планировщик раундов | Round-robin AB/BA - намеренное решение (обе программы играют обе роли). Swiss даст O(N) матчей, но требует продуктового решения о формате | Турниры на 100+ команд |
| Glicko-2 / плагинные рейтинговые системы | ELO достаточен для учебных турниров; head-to-head матрица интереснее - см. «Реплеи» | Вместе с реплеями |
| Инкрементальный лидерборд в Redis ZSET | Живой CTE переписан на UNION ALL (миграция 000038) и опирается на составной индекс; кэш+singleflight смягчают нагрузку | Если лидерборд снова станет узким местом |
| WASM-песочница в браузере | Зависит от внешнего Rust-репо (tjudge-cli) и нового DSL; высокая стоимость | После реплеев и placement-матчей |
| rclone/S3 для бэкапов | Off-site реализован через Telegram-бота (лимит 50MB на дамп) | Когда дамп приблизится к 50MB |
| Retention данных `data/programs/` | Обсуждается отдельно; retention партиций БД реализован (`DB_PARTITION_RETENTION_MONTHS`, по умолчанию выключен) | По мере роста диска |

## Бэклог (ценное, но не начатое)

1. **Placement/smoke-матчи против эталонных ботов** - после загрузки программа
   автоматически играет unrated-матч против tit-for-tat/always-defect;
   мгновенная обратная связь «стратегия жива». Инфраструктура готова
   (executor, очередь с приоритетами, WS); нужны боты в tjudge-cli и понятие
   unrated-матча в домене.
2. **Реплеи матчей** - JSONL-транскрипт итераций из tjudge-cli + страница
   реплея (график счёта, паттерны кооперации). Главная продуктовая фича для
   образовательной платформы; требует изменений во внешнем Rust-репо.
3. **Операторская консоль очереди** - admin-эндпоинты и UI: dead-letter
   список, requeue одной кнопкой, принудительный сброс зависших матчей.
   Частично закрыто авто-retry транзиентных ошибок (миграция 000039 + outbox).
4. **Полный переход фронта на типы из OpenAPI** - кодоген подключён
   (`npm run generate:api`, контрактная проверка в `src/api/contract-check.ts`);
   постепенная замена рукописных типов из `src/types/index.ts` на
   `components['schemas']` при следующих правках страниц.
5. **Модалки вместо нативных confirm()/alert()** в AdminPanel (~19 мест).
6. **Hamburger-меню** - центральная навигация absolute-позиционирована и
   накладывается на лого на узких экранах.
7. **Доделать или выпилить mini-i18n** - en-локаль декоративна (~16 вызовов
   `t()` на 17k строк).

## Сделано (июнь 2026)

- Асинхронная компиляция программ в Docker-песочнице (статус `compiling`,
  builder-образ, очередь, stuck-recovery) - закрыт главный security-пробел
  (host-компиляция недоверенного кода).
- Транзакционный outbox результатов матчей + классификация transient/permanent
  ошибок executor'а (честный retry).
- Лидерборды: UNION ALL вместо OR-join; materialized views удалены.
- Idempotency-Key: скоупинг по пользователю/маршруту, снятие in-flight при ошибке.
- Frontend: TanStack Query на всех страницах, типизированный WS-payload,
  поллинг только как fallback при отсутствии WS.
- Мониторинг: deployments/prometheus + alertmanager (Telegram), алерты из SLO.md.
- Бэкапы: off-site в Telegram, nightly restore-тест.
- CI: фронтенд собирается один раз (артефакт), eslint+vitest в CI, nightly
  full-flow (API+worker+Docker), перф-гейт 10% (benchstat).
